## 🚀 طريقة الاستخدام على Obsidian

يمكنك استخدام الملاحظات بإحدى الطريقتين:

### الطريقة الأولى: تحميل المستودع كـ Vault مستقل
1. حمّل المشروع عبر زر **Code → Download ZIP** أو باستخدام Git:
```bash
git clone https://github.com/OfficialMoAdel/Network.git
```

2. افتح برنامج **Obsidian**.
3. اختر **Open folder as vault** وحدد مجلد المشروع.

### الطريقة الثانية: إضافتها إلى الـ Vault الخاص بك

1. حمّل ملفات `.md` من المستودع.
2. انقلها إلى مجلد داخل الـ Obsidian Vault الحالي لديك (مثلاً مجلد باسم `CCNA`).
3. ستعمل جميع الروابط الداخلية والوسوم تلقائيًا بمجرد نقل الملفات معًا.

## 🤝 المساهمة في تطوير المرجع (Contributing)

هذا المشروع مفتوح للجميع، والهدف منه أن يصبح **مرجعًا عربيًا متكاملًا ومحدّثًا** يفيد أكبر عدد ممكن من الدارسين والمهندسين. مساهمتك — مهما كانت بسيطة — تصنع فرقًا كبيرًا!

### كيف يمكنك المساهمة؟

* **إضافة مواضيع جديدة:** مثل Wireless، Automation (Python/Ansible)، Subnetting، أو لابات Packet Tracer / EVE-NG جديدة.
* **تحسين وتصحيح المحتوى:** تصحيح أي خطأ إملائي أو تقني، أو إضافة شرح أوضح وأمثلة عملية.
* **إضافة أوامر Troubleshooting جديدة:** من واقع الخبرة العملية أو اللابات.

### خطوات المساهمة:

1. اعمل **Fork** للمستودع.
2. أنشئ فرعًا جديدًا لتعديلاتك:

```bash
git checkout -b add-new-topic
```


3. أضف تعديلاتك مع الحفاظ على نفس أسلوب التنسيق المتوافق مع Obsidian.
4. ارفع التعديلات وافتح **Pull Request** مع وصف مختصر لما أضفته.
5. أو يمكنك ببساطة فتح **Issue** لاقتراح موضوع جديد أو الإبلاغ عن خطأ.
